# Ahara Portal Helper

Ahara Portal Helper is a browser extension that automates repetitive tasks inside the Ahara Portal.

## Features

- Navigation automation
- RC number auto-fill
- Member selection
- FAST workflow
- License verification
- Productivity improvements
